# 喵喵茶馆 (Meow Tea House)

原创 HTML5 Canvas 时间管理游戏。你是一只猫咪店长，经营一家珍珠奶茶店：猫、狗、兔子、熊猫、狐狸会陆续来到柜台点单，你要在他们耐心耗尽前做好饮料送到手里。

全部美术为 Canvas 矢量绘制，全部音效为 WebAudio 合成，零网络请求、零外部资源、无构建步骤。

## 玩法

每杯饮品的流程：

1. **冲茶站**：选茶底，冲泡约 3 秒（共 2 个冲泡槽，可同时冲 2 杯）。
2. **加料站**：给冲好的杯子加小料，每杯 1~2 种、不可重复。
3. **摇杯站**：把杯子放进摇杯器摇约 2 秒，摇好后自动回到手里。
4. **出杯**：点击顾客点单票（或按空格）送给点这杯的顾客。手里一次只能拿 **一杯**，手里有杯时不能再冲新茶。

规则：

- 一局 180 秒。每杯得分 = 基础 100 + 剩余耐心比例 × 50（小费，取整），再乘以连击倍率；金币 = 得分 ÷ 10 取整。
- 连续成功出杯，倍率每次 +0.1，上限 ×2.0。出错或订单过期则连击清零。送错的杯子会保留在手里。
- 3 颗星：一个订单过期扣 1 颗，星星扣光立即结束，时间到也结束。
- 做错杯或订单过期了？按 X（或点手里的杯子）倒掉，不扣连击、不扣星。
- 难度只随速度提升：顾客到达间隔变短、耐心变短，订单上限 3 → 4，90 秒后开始出现 2 种小料的订单。
- 如果手里的饮品与某张点单票匹配，该票会高亮闪烁。

## 按键

| 按键 | 功能 |
| --- | --- |
| 1 / 2 / 3 / 4 | 红茶 / 绿茶 / 奶茶 / 果茶 |
| Q / W / E / R | 珍珠 / 布丁 / 红豆 / 椰果 |
| S | 摇杯 |
| 空格 | 出杯（送给耐心最高的匹配顾客） |
| X | 倒掉手里的饮品（或点手里的杯子） |
| P | 暂停 / 继续 |
| M | 静音开关 |
| Shift+R | 重新开始 |
| Enter / 空格 | 标题、结算画面中开始 / 再来一局 |

鼠标全程可用：点茶底按钮、小料按钮、冲好的杯子（选择加料目标）、摇杯器、顾客点单票。

## 本地运行

- 直接用浏览器打开 `game/index.html`（支持 `file://`），或
- 在仓库根目录运行 `python3 -m http.server`，再访问 `http://localhost:8000/game/`。

摆拍场景：在地址后加 `?scene=cover`、`?scene=midplay`、`?scene=serve` 或 `?scene=rush`。游戏状态暴露为 `window.__meow`，方便测试。

## 文件结构

```
game/
  index.html        画布 1280×720 + 无障碍按键说明
  style.css         居中、16:9 自适应、深色暖调背景
  src/
    main.js         启动、主循环、update + render 调度、?scene
    state.js        状态创建 / 重置 / 结束
    drinks.js       茶底、小料、动物、订单生成规则
    orders.js       顾客生成、耐心、过期扣星、出杯判定与计分
    stations.js     冲泡槽、加料、摇杯器、手持一杯约束
    timer.js        SHIFT_SECONDS 与难度曲线
    layout.js       各区域坐标与命中检测
    render.js       茶馆、点单票、工作站、HUD 绘制
    animals.js      5 种动物顾客的矢量绘制
    draw.js         绘制工具（圆角矩形、文字、杯子、星星）
    screens.js      标题 / 暂停 / 结算画面
    scenes.js       摆拍场景 cover / midplay / serve / rush
    audio.js        WebAudio 合成音效与静音
    feedback.js     失败提示（错误音 + 提示文字）
    input.js        鼠标与键盘输入
```
